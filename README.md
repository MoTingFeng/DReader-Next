# DReader-Next

一个精简的 Windows 桌面小说阅读器：**无边框透明悬浮窗 + 老板键**。

用 C# / .NET Framework 4.8.1 WinForms 重写自 DReader 7.3.0.0（易语言静态编译，作者 Dim，最后更新 2022-03）。
原程序已失去维护——静态编译没有源码、无法重新编译，只能重写。

---

## 特性

### 阅读核心

- 打开 txt、拖放文件、命令行传参
- **编码自动识别**：BOM → UTF-16 无 BOM 启发 → 严格 UTF-8 全程校验 → GB18030 回退
- 章节识别（正则 + 归类；识别不出时按 500 行分段）与目录跳转
- 按行分页，进度按行号记录（换窗口尺寸不漂移）
- 阅读进度自动记忆；书签支持插入 / 历史 / 删除 / 跨书跳转

### 摸鱼形态

- **背景全透明**（抠掉键色，只剩文字浮在桌面上）+ **透明度可调**（20%–100%）
- 无边框、按住正文即可拖动、窗口置顶、贴边自动隐藏
- **老板键**与翻页**全局热键**（可在设置面板自定义）
- 鼠标左右半区翻页、滚轮翻页、托盘图标
- 鼠标离开自动隐藏窗口（延迟可设）、鼠标静止隐藏指针、字体变暗
- 单实例运行

### 其它

- 设置面板：字体 / 字号 / 字体颜色 / 自定义底色 / 热键自定义 / 重置
- 自动翻页、跳转页面、比率跳转

## 运行

需要 **.NET Framework 4.8.1**——Win10 21H2+ / Win11 **系统自带，不用装任何运行时**。
下载 exe 双击即用；配置与进度写在 exe 旁的 `data\`（写不进去时回退 `%APPDATA%\DReaderNext`）。

```powershell
dotnet publish src/DReaderNext/DReaderNext.csproj -c Release -o out/publish
```

产物**只有一个 exe，约 76 KB**（另有 174 B 的 `DReaderNext.exe.config`，必须与 exe 放在一起）。
net48 不支持单文件发布，但零第三方依赖，所以 exe 本身就是完整的程序。

## 操作方式

窗口无边框且背景透明，所以操作方式和普通程序不同：

| 想做什么 | 怎么做 |
|---|---|
| 打开书 | 右键菜单 → 打开文件；或把 txt 直接拖进窗口 |
| 拖动窗口 | 按住正文拖动（移动超过 4px 才算拖动，不会误触翻页；文字或文字之间的空白都能按） |
| 翻页 | 点左半区下一页 / 点右半区上一页；滚轮；`PageUp` / `PageDown`；全局热键 |
| 隐藏 / 呼出 | 老板键（默认 `Alt+3`）；或双击托盘图标 |
| 调透明度 | 右键菜单 → 透明度 → 20%–100% |
| 关闭透明 | 右键菜单 → 背景全透明（取消勾选） |
| 鼠标穿透 | 右键菜单 → 鼠标穿透（**默认关**，见下） |
| 反馈问题 | 右键菜单 → 导出诊断日志...，把生成的 zip 附到 GitHub issue（路径已自动打码） |
| 退出 | 右键菜单 → 退出；或托盘右键 → 退出 |

**关于「鼠标穿透」**：透明窗口的抠色像素在 Windows 眼里就是「这里没有窗口」，鼠标会直接落到后面的
窗口上——这是分层窗口（TransparencyKey）的固有行为，改不掉。所以默认把穿透关掉：用一个低层鼠标
钩子把窗口矩形内的鼠标接管过来，于是按住文字**或文字之间的空白**都能拖动、点半区翻页、滚轮翻页、
右键出菜单。代价是窗口矩形内点不到后面的窗口；想点后面，把窗口移开，或勾上「鼠标穿透」退回原行为。

接管是否生效会写在 `data\mouse-hook.log`（安装结果、Win32 错误码、接管到的前三个事件），
拖动/点击出问题时先看这个文件。热键被其它程序占用时状态栏会提示注册失败，不会静默失效。

## 设计取舍

**正文不常驻内存。** 加载时流式扫一遍文件，只记录每行的**字节偏移**（4.5 万行约 0.4 MB）加章节表；
翻到哪一页才按偏移从文件里读那几 KB。之所以能纯字节扫描定位行边界：UTF-8 与 GB18030 的多字节字符
所有字节都 ≥ 0x80，所以 `0x0A`/`0x0D` 只可能作为换行出现，不会被字符内部字节误伤。

**分页以逻辑行计，不以字符计。** 行号不随窗口尺寸变化，进度记录才能在换尺寸后依然准确。

**窗口宽高按逻辑像素存，显示时乘 DPI 因子。** 原程序是 DPI 不感知的，200% 缩放下由系统替它放大；
本程序声明了 PerMonitorV2，必须自己换算，否则窗口视觉上只有原来一半大。
net48 上这件事要**两个地方都声明**：`app.manifest` 写 `dpiAwareness`，**并且** `App.config` 里要有
`System.Windows.Forms.ApplicationConfigurationSection/DpiAwareness=PerMonitorV2`——只写 manifest 的话
WinForms 会把 `DeviceDpi` 一直当 96，窗口就真的只剩一半大（已实测踩过）。

**配色带对比度保护。** 原程序的浅灰字（`#ECECEC`）配浅灰底（`#E8ECEC`）是为「半透明浮在深色桌面」
设计的，用在普通不透明窗口上亮度差只有 0.003、等于隐形；不透明模式会自动换深色字。

**零第三方依赖。** GB18030 由 .NET Framework 自带（不需要 `CodePagesEncodingProvider`），
整个项目不需要任何 NuGet 包，发布产物就是一个 exe。

**配置文件自己读写 JSON。** net48 上没有可用的 JSON 序列化器：`System.Text.Json` 是 NuGet 包
（会多拖 9 个 DLL / 1.16 MB），自带的 `DataContractJsonSerializer` 读不了 ISO 8601 日期，
`JavaScriptSerializer` 又把日期写成 `\/Date(ms)\/` 且回读丢时区。所以 `Data/MiniJson.cs` 只实现
本工程需要的形状（对象 / List / 基本类型 / DateTime / null），输出仍是「缩进 + 中文不转义 + ISO 日期」。

## 排查与反馈

运行时的东西都写在 exe 旁的 `data\` 里（写不进去时回退 `%APPDATA%\DReaderNext`）：

| 文件 | 内容 |
|---|---|
| `last-load.log` | 最近一次打开的书的加载快照：编码 / 行数 / 章节 / 耗时 / 客户端尺寸 / 状态栏文案 |
| `error.log` | 未处理异常的落盘记录（时间 / 类型 / 消息 / 堆栈）——崩溃先看它 |
| `mouse-hook.log` | 鼠标接管状态：钩子是否装上、Win32 错误码、接管到的前三个事件 |
| `settings.json` / `progress.json` / `bookmarks.json` | 配置、进度、书签（可直接手改） |

**要反馈问题**：右键菜单 → 「导出诊断日志...」，会把环境快照（程序版本 / 系统版本 / .NET Framework /
DPI / 窗口尺寸 / 热键与鼠标接管状态）连同上面这些日志打成一个 zip，**所有文件路径自动打码**
（只保留盘符与扩展名，不会带出你在看哪本书），可直接拖进 GitHub issue。

## 已知限制
