# DReader-Next

一个精简的 Windows 桌面小说阅读器：**无边框透明悬浮窗 + 老板键**。

用 C# / .NET 10 WinForms 重写自 DReader 7.3.0.0（易语言静态编译，作者 Dim，最后更新 2022-03）。
原程序已失去维护——静态编译没有源码、无法重新编译，只能重写。

---

## 特性

### 阅读核心

- 打开 txt、拖放文件、命令行传参
- **编码自动识别**：BOM → UTF-16 无 BOM 启发 → 严格 UTF-8 全程校验 → GB18030 回退
- 章节识别（正则 + 归类；识别不出时按 500 行分段）与目录跳转
- 按行分页，进度按行号记录（换窗口尺寸不漂移）
- 阅读进度自动记忆；书签支持插入 / 历史 / 删除 / 跨书跳转

### 摸鱼形态

- **背景全透明**（抠掉键色，只剩文字浮在桌面上）+ **透明度可调**（20%–100%）
- 无边框、按住正文即可拖动、窗口置顶、贴边自动隐藏
- **老板键**与翻页**全局热键**（可在设置面板自定义）
- 鼠标左右半区翻页、滚轮翻页、托盘图标
- 鼠标离开自动隐藏窗口（延迟可设）、鼠标静止隐藏指针、字体变暗
- 单实例运行

### 其它

- 设置面板：字体 / 字号 / 字体颜色 / 自定义底色 / 热键自定义 / 重置
- 自动翻页、跳转页面、比率跳转
- 首次启动可从旧版 DReader 迁移设置与 27 条阅读进度（`Ebook.ini` / `Bookmark.lst`）

## 运行

需要 **.NET 10 桌面运行时**（Windows 10 1809+ / Windows 11 x64）。

```powershell
dotnet publish -c Release -r win-x64 --self-contained false /p:PublishSingleFile=true
```

产物约 **230 KB**（framework-dependent 单文件），位于
`src\DReaderNext\bin\Release\net10.0-windows\win-x64\publish\`。

## 操作方式

窗口无边框且背景透明，所以操作方式和普通程序不同：

| 想做什么 | 怎么做 |
|---|---|
| 打开书 | 右键菜单 → 打开文件；或把 txt 直接拖进窗口 |
| 拖动窗口 | 按住正文拖动（移动超过 4px 才算拖动，不会误触翻页） |
| 翻页 | 点左半区下一页 / 点右半区上一页；滚轮；`PageUp` / `PageDown`；全局热键 |
| 隐藏 / 呼出 | 老板键（默认 `Alt+3`）；或双击托盘图标 |
| 调透明度 | 右键菜单 → 透明度 → 20%–100% |
| 关闭透明 | 右键菜单 → 背景全透明（取消勾选） |
| 退出 | 右键菜单 → 退出；或托盘右键 → 退出 |

默认热键：`Alt+1` 上一页、`Alt+2` 下一页、`Alt+3` 老板键。
被其它程序占用时状态栏会提示注册失败，不会静默失效。

## 设计取舍

**正文不常驻内存。** 加载时流式扫一遍文件，只记录每行的**字节偏移**（4.5 万行约 0.4 MB）加章节表；
翻到哪一页才按偏移从文件里读那几 KB。之所以能纯字节扫描定位行边界：UTF-8 与 GB18030 的多字节字符
所有字节都 ≥ 0x80，所以 `0x0A`/`0x0D` 只可能作为换行出现，不会被字符内部字节误伤。

**分页以逻辑行计，不以字符计。** 行号不随窗口尺寸变化，进度记录才能在换尺寸后依然准确。

**窗口宽高按逻辑像素存，显示时乘 DPI 因子。** 原程序是 DPI 不感知的，200% 缩放下由系统替它放大；
本程序声明了 PerMonitorV2，必须自己换算，否则窗口视觉上只有原来一半大。

**配色带对比度保护。** 原程序的浅灰字（`#ECECEC`）配浅灰底（`#E8ECEC`）是为「半透明浮在深色桌面」
设计的，用在普通不透明窗口上亮度差只有 0.003、等于隐形；不透明模式会自动换深色字。

**不迁移旧热键。** 原配置里 `功能键=4` 的常量含义已无从考证，盲目沿用会把键绑错。

**零第三方依赖。** GB18030 由 WindowsDesktop 共享框架自带，整个项目不需要任何 NuGet 包。

## 已知限制

- **不支持 EPUB**（原程序支持，本重写版未做）
- **不含自动更新 / 检查更新**（原更新地址早已失效）
- 内存约 **20–26 MB**（任务管理器口径），其中约 13 MB 是 .NET 运行时与 WinForms 程序集的
  平台成本，不是书的开销；加载 3.4 MB 的书只额外增加几 MB
